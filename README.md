# BioMIR Privacy Policy and Public Transparency

This repository maintains the public privacy-policy source for **BioMIR**, an iOS health and wellness application. Its role in the broader technical portfolio is to make the product's published privacy commitments inspectable without exposing private health records, proprietary source code, or commercial implementation details.

## Authoritative policy

The authoritative text maintained in this repository is [`index.md`](index.md). The policy describes the current product behavior and user-facing commitments; this README is explanatory and does not supersede or amend that policy.

The published policy addresses:

- user-authorized access to Apple HealthKit and, where authorized, clinical health-record information;
- local, on-device processing and storage as described for the current version;
- the stated absence of developer-operated health-data collection servers for the current app;
- restrictions on advertising, tracking, sale, brokerage, and third-party sharing of health data;
- user control over Health permissions and access revocation; and
- the separation of any prospective future research activity from the current product, including consent and ethics review where required.

These are **published product-policy statements**, not an independent security audit, penetration-test report, HIPAA certification, regulatory authorization, clinical-validation claim, or guarantee regarding future versions.

## Change-control and evidence boundary

Because this repository supports a live product-policy publication, changes to [`index.md`](index.md) should follow an explicit product and legal review. Portfolio documentation can be improved without changing the currently published policy language.

This repository contains no user health records, production credentials, patient data, proprietary BioMIR algorithms, private application source code, or confidential employer information.
